FullStack Learning Academy

Overview

FullStack Learning Academy is a beginner level HTML practice project created as part of my web development learning process.

The project is a result of the learning process on HTML through a YouTube tutorial and practicing.

The project is a set of two connected web pages that introduce Full Stack web development and include a registration form.

The purpose of the project was to learn and practice the implementation of various HTML concepts in a single project.

Project Pages
Home Page
The home page provides an introduction to the concept of Full Stack web development, splits the development process into Frontend, Backend and Database and provides a list of technologies for each part using tables.
Register Page
The register page collects the user input data and allows to select the course.

This project page was created to practice various HTML form elements and to get familiar with the general structure of forms.
Learning Resource
The project was created while learning HTML through a YouTube tutorial.
The purpose of the project was to reinforce the concepts learned through the video by practicing them in a real project rather than building a complex website right away.
